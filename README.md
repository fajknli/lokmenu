# lokmenu

一个为 Wayland 量身定制的高性能、基于标准输入的菜单工具。纯 Rust 实现，专为 CJK（中日韩）文本处理进行了深度优化。

要求 Wayland 合成器支持 `wlr-layer-shell`、`wl_shm`、`text-input-v3` 协议，可选支持 `fractional-scale-v1` 与 `viewporter` 协议以实现高分辨率屏幕上的完美渲染。

## 架构特性

- **零分配匹配算法**：核心模糊匹配基于动态规划（DP）实现。通过 `thread_local` 内存池复用数组，并利用 `Vec::reverse()` 原地反转字符串进行双向匹配，全过程无堆内存分配。
- **精确的 CJK 拼音映射**：建立拼音字符到原始字符索引的哈希映射表。多音字之间插入隐形分隔符（`\x01`）切断跨读音匹配，彻底解决多音字边界问题。
- **O(1) 高亮查找**：渲染层的高亮索引采用 `HashSet` 存储，字符状态判断降至常数时间复杂度。
- **频率权重排序**：在本地缓存中维护选项的调用频率。空查询时按历史频率降序输出；过滤查询时，将频率转化为分数加成（最高 +500），使高频选项自动置顶。
- **类 Readline 文本编辑**：内部维护基于字符的光标位置（`cursor_pos`），支持多字节字符的精确插入、删除与光标移动。

## 依赖

- Wayland 合成器
- 字体
- wl-clipboard (可选，用于支持 Ctrl+V 粘贴)

## 安装

```bash
cargo install lokmenu
```

或从源码构建：

```bash
git clone <repository_url>
cd lokmenu
cargo build --release
# 将 target/release/lokmenu 移动至 $PATH
```

## 匹配逻辑详解

1. **空查询状态**：读取 `~/.cache/lokmenu_history`，按历史使用频率降序排列。频率相同的项按字母表顺序升序排列，保证列表在每次启动时的稳定性。
2. **模糊匹配状态**：
   - 优先级 1：原文双向匹配。将查询词与目标项进行正向与逆向两次 DP 计算，取较高分。输入后缀（如 `der` 匹配 `Blender`）可获得更高得分。
   - 优先级 2：拼音双向匹配。对中文字符生成全拼与首字母字符串，执行同样的双向 DP 计算。通过映射表将匹配到的拼音索引还原为原始字符索引，以实现精准高亮。
   - 历史权重：匹配成功后，将基础得分与历史频率得分叠加，得出最终排序依据。结果数量超过 500 时执行 Top-K 截断。

## CJK 拼音支持

- 支持拼音全拼匹配（输入 `beijing` 匹配 `北京`）。
- 支持拼音首字母匹配（输入 `bj` 匹配 `北京`）。
- 多音字处理：每个读音独立参与匹配，且各读音间插入不可见分隔符，防止跨读音边界的错误匹配（如输入 `qingzhong` 不会误匹配 `重庆`）。
- 混合字符串支持：非中文字符（如英文字母、数字）与中文字符混合时，统一纳入匹配与高亮逻辑。
